# PSSBL Leaderboards: project handoff

A FanGraphs-style stats site for the **Puget Sound Senior Baseball League (PSSBL)**, an adult baseball league with
about 74 teams in 10 divisions. It was built for Matt Bereiter, who plays in the league, and it is an unofficial fan site.

## What the site does

There are four tabs plus a shortcut. All are rendered by `src/page.html` (one script, about 880 lines).

- **Leaders.** Batting or pitching leaderboards in FanGraphs' Dashboard / Standard / Advanced column groups.
  - **Filters:** season (2015–2026, no 2020) or Career, division, team, min PA/IP (default "Qualified"),
    name search, and a **date range** (full season, regular season, playoffs, a month, or custom From/To).
  - **Table:** sortable columns, 50 rows per page, and top-5 leader cards above it.
  - **Sticky header line:** the top 2026 hitter and pitcher, plus Matt's wRC+.
- **Players.** Season-by-season tables with a career row, a wRC+ dot chart (hitters) and ERA-/FIP- chart (pitchers),
  career stat strip, name search, and a link to the player's pssbl.com page. "★ My page" opens Matt (pid 8048).
- **Standings.** Per-division W-L-T, Pct, GB, RS/RA/Diff, Pythagenpat xW and Luck, team wRC+/FIP/oWAR/pWAR,
  and 🏆 for the winner of the division's last playoff game. Clicking a team filters Leaders to that team.
- **Guts!** League constants for every division-season (lgwOBA, R/PA, cFIP, R/W, wOBA weights, …) and a glossary.

## Data source: pssbl.com public API

Base URL: `https://pssbl.com/PHP/fetchData.php?type=…` (public and CORS-enabled; the Tracker app calls it from the browser).

| type | params | used for |
|---|---|---|
| `TeamNames` | `year` | teams → division per season (source of the division list) |
| `CumulativeBatting` / `CumulativePitching` | `division`, `year` | season totals per player (**include playoffs**) |
| `Games` | `division`, `year` | schedule/results; `playoffRound` 0 = regular season; `result` home_win/away_win/tie |
| `BattingStats` / `PitchingStats` | `gameId` | box scores (one line per player per game) |
| `CareerBatting` / `CareerPitching` | `playerId` | per-year totals across all teams; **use these to verify** |
| `Roster`, `FieldInfo`, `BattingLog`, `LineScore`, … | | exist (see pssbl.com/js/services/*.js), not used here |

- **Divisions** active 2016–2026: Adams, Adirondack, Cascade, Denali, Everest, Rainier, Rocky, Sierra, Smoky, Teton.
  Olympic exists in 2015 only.
- **Seasons:** 2020 has no data. Data goes back to at least 2010, but the site starts at 2015.

### Gotchas (all handled; don't regress them)

1. **Team labels in the season totals are unreliable.** `Cumulative*` returns one line per player per division,
   and when a player also filled in for another team, the label is sometimes the fill-in team. That label has flipped
   between pulls (e.g., Michio Koide 2026 Sierra: labelled Rage, really a Mariner with one Rage fill-in game).
   - **Fix:** `compute.main_team()` relabels each single-line player with the team he appeared for most in the
     box scores (ties go to the most recent). Stats are untouched. About 211 lines are affected across 2015–2026.
2. **Fill-ins in box scores.** Box lines carry the team actually played for. `build_box.py` credits a fill-in game to
   the player's own team in that division (as the season totals do), keeping the played-for team in `ptid`.
   Team-games counts for the date filter use `ptid || tid`.
3. **Missing box scores.** About 1–2% of finished games have no box score (2026: 2 of 836). Box-based date-range
   totals can therefore be slightly lower than season totals; about 95% of 2026 lines match exactly.
4. **No intentional walks in box scores.** Date-range wOBA treats all walks as unintentional.
5. **Late corrections happen.** The league edits box scores after the fact (e.g., a Denali game added after Oct 10).
   `update.py` re-downloads the whole latest season, not just new games.

## Sabermetric method (compute.py)

Every number is relative to the **player's own division that season**, treated like AL vs NL.

- **wOBA:** FanGraphs linear weights (BB .69, HBP .72, 1B .89, 2B 1.27, 3B 1.62, HR 2.10), scale 1.20.
  These are the same constants as the PSSBL Tracker.
- **wRAA** = (wOBA − lgwOBA) / 1.20 × PA. **wRC+** = 100 × (wRAA/PA + lgR/PA) / (lgR/PA).
- **wSB:** runSB 0.2, runCS −(2·R/Out + 0.075), minus the league rate.
- **oWAR** = (wRAA + wSB + replacement) / R/W, where replacement runs/PA = 570·R/W/185000 and
  R/W = 9·(R/IP)·1.5 + 3. There's **no fielding or positional adjustment**: PSSBL has no position data.
- **FIP** = (13·HR + 3·(BB+HBP) − 2·K)/IP + cFIP, with cFIP = lgERA − lg(13HR+3(BB+HBP)−2K)/lgIP.
  **ERA- / FIP-** = 100 × stat / lgERA.
- **Pitcher WAR:** FanGraphs-style FIP WAR. FIPR9 = FIP + (lgRA9 − lgERA), a pitcher-specific dRPW,
  and replacement of 0.03 (relief) to 0.12 (start) wins/9 by GS/G.
- **oWAR/600 and WAR/200:** WAR per full MLB season of playing time (× 600/PA, × 200/IP).
  Hitters run high because PSSBL run values per PA are large; Matt chose this scale knowingly.
- **TBF** is estimated as outs + H + BB + HBP (pssbl rarely records BF).
- **Qualified:** 2 PA or 0.5 IP per team game (career: 150 PA / 50 IP). These match the Tracker.
- **Standings:** regular season only. xW is Pythagenpat (exponent = RPG^0.287). The champion is the winner of the
  latest highest-round playoff game.
- **Careers:** sums across all teams and divisions. wRC+ is rebuilt from summed wRAA and league runs;
  FIP/ERA- are IP-weighted.

## Front-end architecture (src/)

- **`shell.html`** defines `window.dash`, a minimal stand-in for the Claude dashboard runtime the page was first
  written for:
  - `dash.data(id)` lazily fetches `data/<file>?v=<manifest.version>` and returns `{status, data}`.
    CSV is parsed with `d3.csvParse`, so cells arrive as text.
  - `dash.onData(fn)` re-runs `fn` whenever a file arrives or the width changes.
  - `dash.colors` and `dash.setLink` (writes the URL hash) are also provided.
  - The rest are no-ops.
- **`page.html`** script, key pieces:
  - **Data access:** `rowsOf(id)` types CSV text once per load (string columns: key, pid, Name, Team, tid, ptid,
    Division, Date, kind, gameId). `memoize(key, deps, fn)` caches derived arrays by reference.
  - **Redraw check:** `render()` redraws only the active tab. `sig()` plus `lastSig` skip redraws when nothing that
    view read has changed.
  - **Dataset ids** (`DS`): `batting`/`pitching` hold the latest season, `batting_hist`/`pitching_hist` hold
    2015–previous, plus `bat_career`/`pit_career`, `standings`, `guts`, and `box_YYYY`. The latest season is the max
    `Season` in guts. History, careers and box scores load only when a view needs them.
  - **Column sets:** `BAT`/`PIT` (dash/std/adv). Formats come from `R3`/`PCT`/`F2`/`F1`; `LOW` lists
    lower-is-better columns (sets the first sort direction); `DEF` holds header tooltips.
  - **Date range:** `rangeSpec()` → `aggregateBox()` sums box lines in range, then `batLine()` / `pitLine()` recompute
    every stat with the season's division constants from guts. This mirrors compute.py, so **keep the formulas in
    sync** if you change one.
  - **State objects:** `L` (leaders), `P` (players), `S` (standings), `G` (guts).
  - **Pagination:** `L.page` / `L.size`.
  - **Matt:** `MATT = '8048'` (gold rows, ★ via CSS, always shown regardless of the qualified filter).
- **Responsive:** `@container (max-width: 760px)` rules (the page sets `container-type: inline-size`).
  The nav scrolls sideways, filters go to a 2-column grid, and leader cards become a swipe strip.

## Analysis findings (analysis/, Oct 2026)

These come from same-player, same-season pairs across divisions.

- **Division difficulty** (same hitter's wOBA vs. Sierra, + = easier):
  Cascade −.042 · Sierra 0 · Adams +.004 · Smoky +.069 · Rocky +.102 · Denali +.111 · Everest +.132 ·
  Teton +.180 · Rainier +.210 · Adirondack +.347.
  - Sierra and Adams are statistically the same level.
  - Cascade is a clear step up.
- **Rocky → Cascade/Sierra:** talent carries over (wRC+ r = 0.42, about the same-division odd/even ceiling of 0.35),
  but wOBA drops about .114. It takes about a 143 Rocky wRC+ to be average in Cascade/Sierra.
  Pitchers (n = 16): FIP- 83 → 115, r = 0.57.
- **Sierra/Adams → Cascade:** wOBA −.043, wRC+ 116 → 104 (n = 232). Pitchers' FIP- 89 → 99 (n = 41).
- **Projection model** (`project_to_adams.py`):
  - Seasons are weighted 5/4/3 by recency × playing time and translated with fixed-effects division offsets.
  - Results are regressed to the Adams average using reliability from split halves: 57 PA (hitters), 12 IP (pitchers).
  - Example output: AJ Hansen .347/.467/.508, 132 wRC+; Cameron Lobb FIP- 81 (≈4.14 FIP).
- **Caveats:** two-division players are self-selected; "easier" mixes competition with environment; no age data.
