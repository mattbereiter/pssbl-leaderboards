Guts! — league constants

Every division-season is its own run environment (like the AL and NL), so wRC+, FIP, ERA- and WAR are always measured against the player's own division that year.

Glossary & method

Built from pssbl.com's cumulative player stats (regular season + playoffs). PSSBL doesn't track fielding positions, batted balls or pitch-level data, so WAR here is a simplified version: hitters get offense + baserunning only (oWAR), pitchers get FIP-based WAR.

PA
Plate appearances: AB + BB + HBP + SF + SH.
BB% / K%
Walks or strikeouts per plate appearance (per batter faced for pitchers).
ISO
Isolated power: SLG − AVG.
BABIP
Batting average on balls in play: (H − HR) / (AB − K − HR + SF).
wOBA
Weighted on-base average: each way of reaching base weighted by its run value (weights in Guts).
wRAA
Runs above division average from hitting: (wOBA − lg wOBA) / wOBA scale × PA.
wRC / wRC+
Runs created; wRC+ scales it so 100 is division average and 150 is 50% better. The best single number for a hitter.
wSB
Stolen-base runs above average, using the division's run value of a caught stealing.
Off
wRAA + wSB: total offensive runs above average.
oWAR
Offensive wins above replacement: (Off + replacement runs) ÷ runs-per-win. No fielding or position credit.
oWAR/600 · WAR/200
WAR per full MLB season of playing time: oWAR × 600 ÷ PA for hitters, WAR × 200 ÷ IP for pitchers. It's a rate, so part-timers aren't penalized; hitters run high because a PSSBL plate appearance is worth far more runs than an MLB one. Tiny samples swing wildly, so use it with the qualified filter.
Qualified
2 PA or 0.5 IP per team game (career: 150 PA / 50 IP), the same bar as the PSSBL Tracker.
IP
Innings pitched; .1 and .2 are one and two outs.
TBF
Batters faced, estimated as outs + H + BB + HBP (PSSBL rarely records it).
LOB%
Share of runners stranded: (H + BB + HBP − R) / (H + BB + HBP − 1.4 × HR).
FIP
Fielding-independent pitching: (13·HR + 3·(BB + HBP) − 2·K) / IP + the division's FIP constant. Strips out defense — which matters a lot in adult-league ball.
E-F
ERA − FIP. Big positive numbers suggest bad luck or bad defense behind the pitcher.
ERA- / FIP-
ERA or FIP as a percent of division ERA; 100 is average, lower is better.
WAR (pitching)
FanGraphs-style FIP WAR: runs saved vs division RA9 by FIP, converted with a pitcher-specific runs-per-win, plus replacement level by role.
R/W
Runs per win: 9 × (R/IP) × 1.5 + 3. High-scoring divisions need more runs to buy a win.
xW / Luck
Pythagenpat expected wins from RS and RA; Luck is wins above that.
